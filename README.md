# Phantom Website Recreation

A recreation of the Phantom website design built using HTML and CSS.

## 🌐 Live Demo

https://shri-ram-n.github.io/phantom-website-recreation/

## 📖 About the Project

This project is a front-end recreation of the Phantom website.

The page focuses on a clean and minimal layout with a responsive design, navigation menu, typography, and image-based content sections.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## ✨ Features

- Responsive website layout
- Clean and minimal user interface
- Navigation menu
- Image-based content sections
- Custom CSS styling
- Responsive design for different screen sizes
