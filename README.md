# Phantom Website Recreation

A front-end recreation of the Phantom website design using HTML and CSS.

## Live Demo

https://shri-ram-n.github.io/phantom-website-recreation/

## About the Project

This project is a recreation of the Phantom website created for front-end development practice.

The website includes a clean layout, navigation menu, typography, image-based content sections, and responsive styling.

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Features

- Responsive website layout
- Clean and minimal user interface
- Navigation menu
- Image-based content sections
- Custom CSS styling
- Responsive design for different screen sizes
